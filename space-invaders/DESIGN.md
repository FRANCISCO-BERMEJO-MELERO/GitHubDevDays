# Design

## Visual Direction

Space Invaders is presented as a compact CRT arcade cabinet: a deep ink-blue field, pixel typography, electric cyan, alien lime, and magenta danger accents. The game board is the visual center, while the surrounding panels behave like readable machine instrumentation.

## Interface Rules

- Keep the game canvas central and immediately visible.
- Use `Press Start 2P` for arcade labels and `Chakra Petch` for readable UI copy.
- Reserve cyan for primary information and interactive focus, lime for positive action, and magenta for danger or lives.
- Preserve strong keyboard focus states and visible game status.
- Keep the responsive layout playable on narrow screens without hiding controls.
